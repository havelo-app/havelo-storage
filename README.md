# Havelo Storage

Keeps Havelo's favorites, views, cards and maps in sync across your devices, on a server you run.

## Home Assistant OS or Supervised

[![Add this repository to your Home Assistant](https://my.home-assistant.io/badges/supervisor_add_addon_repository.svg)](https://my.home-assistant.io/redirect/supervisor_add_addon_repository/?repository_url=https%3A%2F%2Fgithub.com%2Fhavelo-app%2Fhavelo-storage)

Then install **Havelo Storage** from the app store. Or add `https://github.com/havelo-app/havelo-storage` in the app store's **Repositories** menu.

## Docker on Linux (amd64 or ARM64)

The image is `ghcr.io/havelo-app/havelo-storage`. Pick an example in [`examples/`](examples) and follow the [setup guide](SETUP.md).
